# The Exit 8 — Unreal Engine Systems Study

A personal Unreal Engine 5 project created to study looping-level logic, anomaly behavior and environmental pacing. It is inspired by *The Exit 8* and is not an official release or commercial credit.

## My contribution

- Implemented anomaly behavior and the win condition.
- Built forward and backward level transitions for the looping corridor.
- Integrated footsteps and ambient audio.
- Added gameplay Blueprints for doors, teleportation, security cameras and environmental interactions.
- Explored AI behavior trees, blackboards, roaming and chase tasks.

## Technical details

- **Engine:** Unreal Engine 5.3
- **Project type:** First-person Blueprint project
- **Systems represented:** Blueprints, AI behavior trees, level transitions, audio and environment interaction
- **Optional plugins used by the project:** Substance, Water, Water Extras and Niagara Fluids

## Open the project

1. Install Unreal Engine 5.3 and the plugins listed in `The_Exit_8.uproject`.
2. Clone the repository with Git LFS support if required by your environment.
3. Open `The_Exit_8.uproject` and allow Unreal Engine to prepare derived data locally.

The repository contains binary Unreal assets and third-party environment resources. Those assets remain credited to their respective creators and are included only as part of this educational project.

## Why this project matters

The main challenge was keeping anomaly state, player direction and level progression coherent while hiding transitions from the player. It helped me practice systems thinking inside a content-heavy UE5 project.
